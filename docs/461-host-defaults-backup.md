# 管理员主机创建默认配置备份与恢复

2026-09-14。补齐 F14/B15/A37 中实例级 host_defaults 的实际迁移路径。

## 契约与边界

备份格式3新增可选 hostDefaults，旧备份缺少该字段时不修改目标全局默认值。数据库快照仅对当前管理员包含该设置。可迁移字段覆盖代理主机/端口/用户名/启用意图、监控与状态检查默认开关、终端字体字号主题光标、会话记录和命令历史默认开关。密码和源数据库 credentialId 不进入备份；未知字段由原有导入投影排除并给出字段忽略提示。

恢复使用独立 restoreHostDefaults 布尔参数，默认 false，与界面偏好和快捷键选项分开。确认界面明确说明管理员权限、覆盖全局默认值、代理停用及凭据重新配置。恢复后强制 useSocks5=false、credentialId=null，不保留目标旧密码，以免给新代理误配旧认证。监控等配置只是新建主机时的默认值，导入本身不创建连接或执行命令。

事务开始重新读取 users.isAdmin；普通用户或预览后被撤销管理员权限者返回 BACKUP_ADMIN_REQUIRED（HTTP403、中文提示）。默认配置和管理员身份纳入目标快照指纹，预览后相关变化要求重新预览。独立确认选项进入服务幂等状态与摘要。全局配置、主机、流程和导入收据在同一 SQLite 事务提交；失败回滚，成功后更新设置缓存。

## 文件责任与依赖

- types/backup-host-defaults.ts 拥有此备份字段的无秘密契约与安全恢复投影；只依赖 zod，不依赖页面或数据库。
- configuration-backup/schema.ts/service.ts/http-routes.ts 分别负责文件投影、预览与确认状态、HTTP参数与错误。
- ConfigurationBackupRepository 负责管理员身份复核、快照、事务和缓存更新。
- ConfigurationBackupPanel 和对应 API 适配层编排独立选项及结果提示，中英文资源同步。
- 未修改原管理员设置编辑接口或数据库结构。新模块仅承载备份领域契约，没有抽取通用工具或引入反向依赖。
