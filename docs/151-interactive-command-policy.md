# 已知交互终端工具的规则判断

2026-09-12，alpha.7标签之后的开发修复。A12要求无法判定的Shell/解释器/TUI不能被当成已通过安全判断。现有不透明程序集合包含Shell/解释器，却遗漏常见TUI。

加入vi/vim/nvim/nano/emacs、less/more、top/htop/btop、tmux/screen。普通模式即使命中程序允许规则和任务预授权仍返回unknown并要求人工审查；严格模式直接deny，单次批准不能绕过。人工自由终端入口仍由既有控制权机制处理。这是按程序族的保守判断，帮助或批处理参数也不自动解除分类；不宣称识别所有自定义程序、别名或提供远端OS沙箱。

每个程序及/usr/bin绝对路径变体均验证普通/严格模式、预授权、单次批准和零写入，连同既有网关/schema共44项通过。ESLint、tsc -b及中文缺失键检查通过。中英文说明同步补上交互式终端工具，避免把TUI错误描述为脚本。A12整体仍需按原范围完成审查，不以这份已知名单声称无限覆盖。

生产改动局限在命令策略分类与说明；无新共享抽象，没有改变人工终端或其他SSH会话接口。已推送的alpha.7标签保持不变。
