## 边界与验收

上传对话框负责销毁旧的不可变远端预览并提交新名称；UploadTreeService 负责从父子关系计算目标路径并通过 SFTP 写入。下载对话框负责重查并清空选择；DownloadDirectoryTargets 负责预览版本校验和本地目标映射，DownloadSink 负责实际字节落盘。测试不从 UI 模拟返回值推断真实路径正确性。

新增真实 SFTP 上传测试：原目录含同名文件，改父目录名称后销毁旧预览，旧确认返回 UPLOAD_NOT_FOUND；新预览未确认不能创建目录。显式确认后，文件和空目录都位于新的中文父目录，原文件字节保持不变，原目录未新增空目录。

新增实际本地文件系统下载测试：相同目标根重新预览产生新 revision，旧 revision 确认及未确认创建被拒绝。显式确认后，二进制文件与空目录写入新父目录，原文件及原目录清单不变。

新增上传、下载界面测试各一项：先选择合并与覆盖，再修改父目录名称；开始按钮禁用，重新检查提交新父名称并保留子文件 parentId，重查后父目录和子文件的冲突选择均为空，不自动启动。上传同时检查旧预览被释放。
