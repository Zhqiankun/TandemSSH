# 独立可恢复的人工暂停任务

2026-09-13，补齐 02-experience 第 6 节与 F04 的独立暂停入口。

## 用户行为

新增“暂停任务”，与取消任务和立即接管分别显示。暂停停止后续模型请求/动作派发、保留任务和已有记录、交还控制权，不发送 Ctrl+C，也不声称结束已运行的远端进程。已有发送但结果未知的操作仍需人工核对，之后通过原授权表单继续。

## 模块与契约

- TaskRuntime.pauseTask：仅 human 主体且任务属于当前用户；拒绝已结束或归档中的任务；已暂停请求幂等。使用既有暂停与控制权失效机制，状态 paused-human，原因 TASK_PAUSED_BY_USER，记录 task.paused。审计失败不会阻止人工停止派发，保留 AUDIT_UNAVAILABLE 提示。
- POST /tandem/tasks/:id/pause：继承现有认证，严格空请求体，ID 校验及现有分页投影。MCP 工具目录没有增加暂停工具，不能把人工授权能力开放给模型。
- collaborationApi.pause：只做 HTTP 适配。
- useTaskWorkbench：暂停与接管共用本 Hook 已有的控制操作并发和会话生命周期保护，不依赖页面私有状态。
- TaskPanel：独立中文按钮、说明及恢复入口；不使用取消 API。暂停按钮不被普通任务请求的 busy 阻塞，但与进行中的控制操作互斥。
- 英文、简繁中文文案与时间线事件名已补齐；其他语言使用新增英文回退。部分语言原本没有 tandem 扩展段，写入脚本初次失败后补齐对应结构，不重复插入代码。

没有新增共享模块、数据库迁移或反向依赖；只扩展现有任务公开用例和 HTTP 契约。

## 实际验证

后端 task-runtime 与内置 AI workflow-task：2 文件、52 项通过。新增覆盖自动/协作暂停当前操作、写入字节不含中断、未知结果需核实、重新授权后原流程继续；MCP/其他用户不可调用人工暂停、取消后不能复活；内置 AI 暂停期间不再请求模型。

中文 TaskPanel 与工作台会话回归：2 文件、18 项通过。按钮调用 pause 而非 cancel，写入不增加，状态可恢复，重新授权表单出现。

TypeScript、修改文件 ESLint 通过，缺失静态翻译键 0。测试中的远端和模型端口受控，不代替真实桌面/SSH 验收。HTTP 路由专项及实际 Windows 客户端暂停交互仍需继续；F04 不标记完成。
