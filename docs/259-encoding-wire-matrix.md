# 固定字节的编码、BOM 与换行验证

2026-09-13，A31 编码侧证据。

新增 encoding-wire.test.ts，预期数据使用固定十六进制字节，不调用生产编码器生成预期结果。中文样本为“中文”，覆盖 UTF-8、UTF-16 LE/BE、GBK、GB18030，Unicode 编码有/无 BOM，换行 LF/CRLF/CR/无换行，共 32 种组合。逐项验证解码文本与格式、编码输出字节；有 BOM 时同时验证自动识别。

另外 6 项覆盖非法 UTF-8、截断 UTF-16 LE/BE、截断 GBK、文件签名之后的真实 U+FEFF 字符保留、显式编码与 BOM 冲突。不能安全往返的输入返回非编辑文本原因，不能以替换字符静默修复。

与 document-service.test.ts 一起运行：2 文件、62 项通过（38 项新固定字节测试 + 24 项文档服务测试）。本轮不声称覆盖编码的全部 Unicode 映射表；补充的是独立于实现生成逻辑的字节基准。

生产逻辑没有修改，没有新增共享抽象或模块依赖。A31 仍需中文桌面编码选择/有损转换反馈及特殊文件名组合证据。未提交、推送或发布。
