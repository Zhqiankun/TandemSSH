# 新建文件与目录的独占创建

2026-09-12，alpha.6 标签之后的开发改动。

原实现使用 touch 和 mkdir -p：同名文件/目录已存在也会返回成功，touch 还可能改变已有文件时间。现新增 file-manager/create-item.ts，由 SFTP OPEN 的 wx 独占创建文件、SFTP MKDIR 创建单个目录；没有“先判断不存在再覆盖”的写入路径，不截断、不合并已有目标。文件成功打开后关闭句柄才返回；关闭失败或请求超时为 CREATE_RESULT_UNKNOWN。迟到句柄尝试关闭，不自动删除目标，也不声称回滚。

模块责任：create-item 封装名称/路径构造、SFTP 独占操作和结果分类；operation-routes 保留认证会话、用户所有权检查、协议与状态码转换。UI 继续编排原操作，针对 FILE_TARGET_EXISTS 与 CREATE_RESULT_UNKNOWN 提供中英文提示。单条新建名称不能是 .、..、斜杠或空字节；保留中文、引号、空格及换行，Windows 目录分隔符规范化。多级目录工作流有独立入口，不通过单个名称越级创建。

20 项针对性回归通过：文件/目录独占成功与冲突、特殊字面量名称、Windows 路径规范化、非法名称、句柄关闭失败、超时后迟到句柄清理，以及真实路由到 SFTP 服务的冲突409/权限403/未知500映射。ESLint 0 错误，FileManager 保留 1 条已有 windowId 警告，中文缺失键 0。

这些是 SFTP 夹具测试和路由调用测试。下一步需在真实 OpenSSH 验证已有文件、目录、断链等目标拒绝及完整桌面新建体验；不把 B09 标记完成，也不改写已公开 alpha.6 的源码标签。
最终 tsc -b 类型检查通过。
