# 普通聊天历史会话入口

## 实现

新增 AiConversationPicker，在现有紧凑聊天标题区下提供历史选择、新会话和刷新按钮。调用既有 getAiConversations，不访问后端私有数据。当前接口返回最近 50 个会话，未增加分页。

AiPanel 负责切换：停止并重置旧流，清理旧正文/提议状态，加载所选会话的正文与失败/中断标记，恢复其 providerId 和 model。续聊沿用所选会话 ID、模型；新会话清空 ID 和历史模型。原提供方被删除时不静默使用其他模型，需要用户选择。

加载中及加载失败时禁用输入和发送。选择请求及完成后的历史刷新均带选择版本校验；切换或卸载后迟到的响应不能覆盖新会话。目录组件自己的请求也有失效保护。

模块依赖：历史目录组件 → 公共 AI API；AiPanel 编排选择和流生命周期；useAiStream 继续负责请求取消；显示组件不访问后端。没有新通用共享抽象、后端接口或权限变化。界面沿用项目现有样式与 React 技能约束。英文、简繁中文文本已提供，其他语言用英文兜底。

## 验证

新增 AiPanelHistory.test.tsx 四个场景：打开历史及未完成状态、按原模型续聊和新会话；快速切换时迟到选择响应被忽略；加载失败禁发；旧完成回调的历史刷新不能覆盖新选择。流 Hook 的原有取消与旧响应测试一并执行。

AI 前端全目录 **6 文件、34 项通过**。Hook 整理后历史面板专项 **4 项通过**；TypeScript 通过；新增 Hook 警告已处理，修改文件 ESLint 无错误；翻译字面调用缺键为 0。

初轮测试失败属于夹具：react-i18next 替身缺少下游初始化导出，以及项目未启用 toBeDisabled 匹配器。修正替身与原生 disabled 断言后通过，不是运行时产品故障。
