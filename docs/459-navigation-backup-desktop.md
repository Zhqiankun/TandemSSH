## 实际执行

使用当前生产构建生成本地 win-unpacked 目录包（--publish=never），在专属临时配置中启动 TandemSSH。通过中文备份页面执行预览导出、真实下载、选择文件、勾选恢复、确认导入和手动重新加载，再以同一配置目录冷启动。

源设置隐藏“串口”而显示“连接”；目标设置反过来。验证导出的格式3文件包含源配置，下载与预览逐字一致。恢复后实际侧栏重新隐藏串口并显示连接，数据库和 localStorage 同步，AI 用户开关保持 false。恢复选项初始未勾选，导入和重启没有自动创建任务或会话。

沿用的应用设置验收同时验证 Nord、字号、强调色及快捷键审阅流程：导入快捷键保持禁用且使用新 ID；片段引用不复用；手工审阅一项不会启用另一项。
