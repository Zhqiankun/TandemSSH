## 本轮核实的交付事实

- GitHub releases API 返回空列表，尚无公开 Release。CI 和安装/升级夹具成功不能替代公开下载渠道验证。
- 实际 Windows 包 ASAR 顶层未包含 LICENSE/NOTICE/UPSTREAM，根目录仅有 Electron/Chromium 声明。本轮补齐 4 份项目/上游文本并要求与源码一致；完整第三方依赖及图标/字体清单仍未完成。
- configuration-backup/schema.ts 的投影只导出基本主机字段；恢复仓库明确写入 jumpHosts/tunnelConnections 空数组，且快照不含 C2S 预设。因此网络配置备份属于确定缺失，不是单纯缺测试。
- 53—64 后续文档已补齐部分旧文档列出的认证接线；不能将旧“监控尚未接入”等时点记录直接当作当前缺陷。
- 68 的真实结果文件证明自动/协作均因超量模型响应暂停、未执行工具、人工输入可用；这不证明全部模式/文件/认证组合。

## 推进顺序

1. 完成发行包项目许可文本的实际交付和验证；继续独立补第三方依赖/资源清单。
2. 补网络配置备份：跳板机、主机隧道与 C2S 预设一起处理，重建引用、排除凭据、保持不自动启动，事务/预览/幂等沿用现有边界。
3. 按 B02/B04—B13 补齐真实矩阵，包括文件权限/链接/项内恢复、监控字段全集、全部适用转发模式与重连。
4. 收口记录/历史/全局资源限制，完成品牌/汉化扫描与安装包演示。
5. 公开 alpha 前完成上表所有门禁、真实 Release 下载更新和历史数据迁移验收。已有授权持续有效，不重新要求用户批准已确认范围。
