# 自动补全历史的异步隔离

2026-09-14，继续F03历史与快捷输入联动。

原Terminal.tsx直接把异步getCommandHistory结果写入同一ref，没有取消或主机校验；加载期间新增/删除也可能被稍后返回的旧快照覆盖。旧删除回调在主机切换后可能继续更新当前历史上下文。

新增终端业务Hook useAutocompleteHistory，每个hostId/enabled组合拥有独立缓存。布局提交阶段失效旧缓存回调；旧请求完成不覆盖新主机。等待远端快照时记录本地新增/删除，按编辑顺序合并，重复命令去重并限制可见缓存500项；加载失败保留已接受的新命令。成功删除后的旧主机回调返回false，调用方不再更新新主机上下文。

Terminal.tsx改为通过Hook增删和读取缓存，移除内联异步加载。长期输入回调使用同步更新的当前新增函数引用，键盘处理器在缓存作用域变化时重新绑定，避免新Hook接入后仍捕获旧对象。

## 边界与验证

模块职责为单个终端的补全缓存与请求合并，依赖UI命令历史API，不依赖后端私有模块；不是新增全局shared缓存，不新增数据库/API契约。

15项相关测试通过，涵盖旧主机迟到快照、加载中增删与去重排序、旧回调拒绝、关闭后清空、加载失败保留新记录及500项上限，以及原输入跟踪回归。日志.cache/autocomplete-history-tests.log。

首轮测试初始化beforeEach返回了mockReset得到的mock函数，被测试框架作为清理回调调用，导致已拒绝的夹具Promise在清理阶段报错；改为不返回函数后重测通过。另一次编辑辅助脚本语法失败未应用布局失效变更，已明确识别，随后写入正确代码并重新验证，不将旧版本通过当作最终结果。
