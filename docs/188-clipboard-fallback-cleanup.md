# 剪贴板回退异常清理

2026-09-12 检查 B11 复制远端路径时，确认 FileManager 已将选中项原始路径以换行分隔交给 copyToClipboard，并根据布尔结果显示中文成功或失败提示。发现兼容回退在 document.execCommand 抛错时，遗留包含路径的隐藏 textarea；粘贴回退同样遗留临时节点。

## 边界与修复

既有 ui/lib/clipboard 是无业务归属的系统剪贴板适配入口，供文件管理器、终端及其他界面调用。本次不新增模块或改变依赖，仅把临时 DOM 节点的释放移动到 finally。成功返回值、失败返回 false/空字符串、Electron 优先与浏览器回退顺序不变。清理只移除本次创建的节点，不清空其他编辑器或剪贴板。

## 验证与剩余范围

clipboard.test.ts 和 file-terminal-path.test.tsx 共 18 项通过。新增复制、粘贴异常用例证明临时节点消失且现有输入内容保留。针对性 ESLint 通过；TypeScript 类型检查通过。

这是浏览器回退生命周期修复，不作为系统剪贴板完整桌面复制路径验收。B11 仍需复制路径及打开本地下载目录的桌面证据。已发布 alpha.9 不含本次修改。
