# 扩展未知命令的版本和文件名分类

2026-09-12，在 alpha.12 公开发布后继续 A12。生产规则原先仅按精确 basename 列表判断未知命令，python3.12 即使命中程序白名单，也被判为普通 allow。自动/协作两个用例已在修复前复现（期望 unknown，实际 allow），日志 `.cache/versioned-opaque-reproduction.log`。

## 变更

在 command-policy.ts 内增加保守名称分类，规则组合模块仍拥有此职责，不引入新的共享层或网络访问：

- 路径取最终名称，兼容正反斜杠，分类时忽略大小写；已知名称支持 .exe/.com 后缀。
- 常见解释器和 Shell 的数字版本后缀（含 Python t/d 形式）按已知家族识别，使用固定且首尾锚定的表达式，不接受用户任意正则。
- 直接执行常见脚本扩展名时标为 unknown。
- 补齐 Python/Node 别名、PHP/Lua/R 以及常见容器工具；无法判定行为时不被程序允许规则直接放行。
- 允许规则的程序/参数精确匹配不变；只对未知分类作调整，不擅自把同名或近似名视为同一个被允许的程序。
- 中文原因调整为“该命令的执行行为需要人工审阅”，不把所有情况都称为脚本内容。

非严格模式需要明确审阅；严格模式拒绝，任务预授权或一次批准不能绕过。人工自由终端不受此分类限制。

## 验证

网关 134 项、中文策略界面 14 项，共 148 项通过。覆盖版本化名称、Windows 名称/路径、脚本路径、容器工具、自动/协作及 basename/限定路径；反例保证 python3-config、node_exporter、bashful 不因子串误判，也不把参数中的 script.py 当作执行脚本。

因修改影响三类执行入口，额外执行 collaboration、ai、mcp 后端回归：60 文件通过，570 项通过、1 项跳过，37.01 秒，报告 `.cache/opaque-classification-regression.json`。该回归包含前述网关测试，数量不能相加当成独立测试总数。真实 PTY 文件未在本轮重复运行。ESLint、TypeScript、中文检查和 diff 检查通过。

## 边界与发布

这是程序名称的保守分类，不读取远端可执行文件内容、不解析符号链接，也不证明任意重命名程序的真实行为。客户端规则不是 OS 沙箱；A12 的程序身份和未覆盖解释器边界仍需核对，不标为整体完成。

该修复发生在 alpha.12 标签之后，尚不包含在已公开安装包内；后续版本再按完整门禁发布，不改写 alpha.12。
