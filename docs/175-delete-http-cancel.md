# 普通删除的 HTTP 中止处理

2026-09-12。继 174 的超时上限，在普通永久删除尝试中接入请求 aborted 和响应 close。响应未正常结束而关闭时取消本次尝试；请求开始时已 aborted/响应已 destroyed 也直接结束，不进入 execChannel。

取消只关闭本次活动通道、清除定时器与事件监听、结束服务端等待，不向已离开的客户端发送结果。已排队请求的 beforeOpen 通过 settled 拒绝后续派发，迟到通道回调只销毁通道，迟到权限结果不再调用 sudo。正常完成、错误与超时共用清理过程；正常 writableEnded 响应不作为取消。

已派发远端命令可能已经产生变更，关闭通道不是回滚证明；没有新增自动重试或撤销原操作的声明。
