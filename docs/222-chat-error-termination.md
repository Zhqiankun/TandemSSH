# 普通聊天模型错误终止

## 复现

真实 Express HTTP 测试注入助手工具调用后立即产生中文模型错误。旧路由响应先 error、再 done，并将尚无工具结果的助手调用保存为普通历史。这与失败应停止的语义不符，也可能令后续模型请求遇到未配对的工具调用。

## 修改

`ai/index.ts` 在收到引擎 error 时交付错误、结束响应并退出路由，finally 仍清理心跳。成功路径仍先保存再完成。没有数据模型、工具执行器、权限或共享模块变更；本轮没有引入自动重试。

`chat-persistence-order.test.ts` 新增模型错误回归，断言保留错误、不发送 done、不写入助手普通历史，已保存用户消息保留。既有保存失败、成功多轮工具回放继续通过。

## 验证与限制

chat-persistence-order、chat-history、chat-delivery、engine 共 4 文件、23 项通过；TypeScript、ESLint 通过。模型、仓储是测试替身，HTTP/SSE 为真实回环服务；不代表实际付费模型或桌面验证。

失败流中已经显示的片段及此前已完成工具结果，当前没有作为独立“未完成记录”持久化。本修复仅阻止误报完成及半截调用被当成普通历史；并不完成聊天中断恢复。该剩余项必须继续实现，不能将丢弃失败片段当作最终产品行为。未发布新安装包。
