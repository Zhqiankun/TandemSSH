# 保留补全前缀中的空格

2026-09-14，继续F03/B03快捷输入边界。

原Tab补全把整个已输入命令trim后匹配，已输入的尾部空格被忽略，可能重复追加空格；例如printf后引号中的空格会因此改变参数内容。鼠标选择、键盘选择和单候选各自计算substring，也会把本地行直接替换为历史候选，丢失原前导空格。

新增终端业务规则command-history/completion.ts：匹配时仅略过前导空白，尾部空格参与前缀匹配；返回缺少的suffix和原输入+suffix形成的line，不改写已输入部分。三条路径共用此规则。空前缀、已完整相等、不兼容前缀和带C0/DEL控制字符的候选返回null，不把换行、Tab或ESC通过历史补全直接发送。

职责为历史补全的纯领域规则，无API、数据库或通用shared依赖；Terminal只负责事件和发送。普通手工输入、显式粘贴等路径不被这一候选过滤规则限制。

28项相关测试通过，覆盖前导/尾部空格、引号内参数空格、中文/emoji后缀、不兼容或控制字符候选，以及补全缓存/输入跟踪回归。日志.cache/history-completion-tests.log。
