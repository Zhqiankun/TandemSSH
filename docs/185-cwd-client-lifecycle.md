# 终端目录查询客户端生命周期

2026-09-12。核对 183 的客户端实现发现，设置 pending 后 WebSocket.send 若抛错，或响应一直未到，后续点击会持续认为查询正在进行。

新增 terminal/directory-query.ts，仅拥有单个终端组件的目录请求状态。TerminalDirectoryQuery 负责固定协议发送、同一上下文去重、20 秒客户端等待上限、失败/完成/卸载清理，以及 requestId/主机/当前 WebSocket 的响应匹配。Terminal.tsx 保留用户确认和中文反馈，组件卸载时 dispose；不将业务状态放入通用 utils。

发送前重新检查 WebSocket OPEN，发送抛错清除请求及计时器；响应丢失后释放等待状态，允许用户重新确认后重试。旧主机、旧连接和旧请求的响应不会消耗当前请求。新上下文替换旧请求时取消旧计时器，卸载不再触发超时提示。

客户端超时不表示远端回滚或强制停止；后端目录查询仍有 15 秒有界等待。没有新增自动重试、自动接管或任意命令入口。
