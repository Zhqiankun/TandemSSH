# 模型 API Key 仅本次运行使用

## 功能

模型创建与编辑支持显式选择“Key 仅在本次运行使用”。提供方地址、名称和模型仍正常保存；Key 与显示前缀不写入数据库。运行期间显示“临时 Key”，重启后提供方保留、Key 为未配置，可在编辑窗口重新输入。

未勾选时继续采用原有先加密后写入；系统用户密钥不可用时不退回明文。更换内存 Key 会清除该提供方原持久化 Key。留空仍保留当前 Key，修改存储选项而不输入新 Key 不暗中迁移旧秘密。

## 边界与责任

- AiRepository 是统一密钥读取入口，模型发现、普通聊天与内置 AI 任务沿用该入口。公开提供方记录不返回 Key，只返回掩码前缀与 memory/encrypted/none 状态。
- 新 ai-session-keys.ts 只管理进程内 Buffer，无文件或日志访问。单 Key 限 16 KiB，256 个名额计入待保存预留；替换时可临时保留旧 Buffer。
- 数据库操作前预留名额，写入成功后提交，失败丢弃。退出/权限关闭、删除或新替换会撤销待提交 Key，旧异步保存不能重新激活它。
- 修改提供方地址/类型或停用时先清除旧临时 Key；删除、退出登录、批量会话撤销、OIDC 后通道退出和关闭 AI 权限也清理对应用户或全局临时 Key。
- UI 负责显式选择与中文提示，不访问秘密存储。没有数据库字段迁移，不引入跨业务通用秘密工具。

## 验证

实际 SQLite 仓储测试在 DataCrypto.getUserDataKey 返回 null 时创建 memory 提供方，数据库 api_key/api_key_prefix 均为 null，统一读取入口仍取得临时 Key；其他用户不可读取。另覆盖加密→内存轮换、地址变更、删除、保存中退出不复活、名额上限和 AI 关闭清理。

组件测试验证编辑窗口明确选择 memory 并传递存储模式。AI 相关回归 35 文件、225 项通过；补充认证/退出回归 5 文件、28 项通过。TypeScript、最终修改文件 ESLint、翻译键检查通过。

真实 Windows 目录包使用独立配置和本机模拟模型验证，报告：

创建/轮换临时 Key 能实际调用模型；正常退出重启后 apiKeyStorage=none、前缀为空、配置保留；重新输入临时 Key 后再次可用。共 4 次本机模型发现请求，两个桌面进程及观察脚本正常退出。restore/memory-key-settings.png 已查看，中文提示与选中状态可见，没有拍摄输入中的完整 Key。

## 当前限制与交付状态

仓储加密不可用故障注入与正常系统加密环境下的真实桌面生命周期分别验证；尚未完成同一桌面中系统加密故障与手工切换选项的组合验证，A16 暂不标记完全验收。进程已向模型发出的请求不能通过清除内存撤回。

遵照最新要求，本轮仅修改与验证本地代码，没有 Git 提交/推送、版本标签或 Actions。该功能不在已公开 alpha.14 内，最后统一交付。

## 单会话撤销补充

user-session-routes 已核实目标会话所属用户，现将该可信 userId 与 sessionId 一并传给 AuthManager.revokeSession。撤销前清理目标用户全部临时 Key 及待提交记录，避免管理员操作时清错为管理员自己的 Key；不额外查询数据库。

新增测试保留另一用户的 Key，验证目标 Key 消失、待提交 Key 无法重新提交，且原会话撤销仍被调用。认证、OIDC 和临时Key池共 3 文件、12 项通过；TypeScript、ESLint 通过。本补充仍为本地未提交改动。
