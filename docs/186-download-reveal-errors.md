# 下载项定位失败提示（B11，局部验证）

## 需求与边界

下载完成后可在系统文件管理器中显示本地下载项。定位失败属于打开动作失败，不能显示为下载失败或改变已完成传输状态。

本次不新增共享模块。Electron download-ipc 负责检查已授权下载目标、文件存在性及调用系统定位入口；DownloadQueuePanel 仅编排动作和中文提示；下载队列与传输状态机不变，界面通过既有 IPC 调用，不能传入任意本地路径。

## 变更

- 单文件与目录下载共用 IPC 内部 reveal 方法；读取本地目标前仍检查完成状态及所有权。
- lstat 失败或系统定位调用抛错返回 DOWNLOAD_SHOW_FAILED，不透传原始系统错误。
- 存在检查结束后重新校验窗口、授权生命周期和下载能力，避免异步期间已撤销能力继续打开。
- 定位失败独立提示：无法在文件夹中显示下载项，请确认文件仍然存在且系统文件管理器可用。下载状态未改变。
