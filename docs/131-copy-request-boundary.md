# 复制请求边界与连接拒绝

2026-09-12，位于 alpha.6 标签之后，不改变其构建源码。

复制路由此前只检查参数真假值，数组/对象路径仍可能进入 split/replace，空请求体还会在解构处失败。现在 req.body 缺失按空对象处理，sessionId/sourcePath/targetDir 必须为非空且不含空字节的字符串，否则返回 400 INVALID_COPY_REQUEST，未派发 SSH。路径中的正常空格、中文和换行没有被擅自拒绝。FileManager 针对该错误显示中英文刷新后重选提示。

15 项复制路由回归通过：无输出成功/失败、分段输出单响应、流错误、缺失退出状态，以及七类非法请求、会话不存在/断连/权限拒绝。后几类均断言没有打开远端命令通道。后端 ESLint 与 TypeScript 通过；中文缺失键 0，UI ESLint 0 错误、1 条既有 windowId 警告。

该修改是协议边界校验，不改变正常复制命名、冲突选择或流程控制。复制目标命名冲突、执行超时及整批部分失败的进一步实机验收仍保留；不据此完成 B07/B09。
