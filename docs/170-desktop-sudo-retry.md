# Windows 桌面错误 sudo 密码恢复

2026-09-12，源码基线 2045283。使用最新源码的本机桌面目录包、独立用户配置和隔离 Linux SSH 实例，验证 169 修复的错误密码恢复流程。本轮没有新增生产代码或外部依赖。

## 实际步骤和结果

专属实例 ce07cdd5-6eb1-417e-8c0d-790281e62486，网络保持 restrict=on，sudo 按 167 的官方 APK 离线安装方式准备，要求密码并经 visudo 检查。测试只涉及该实例中的唯一目录和受限文件。

在文件界面发起删除，明确确认永久删除后，出现中文 sudo 密码对话框。输入固定错误测试密码并提交，界面显示“提权删除未能确认成功。请先核对文件状态，再重新发起操作并输入密码。”；独立 SFTP 确认文件仍存在、内容为 fixture。

再次从文件界面发起删除，再次明确确认，密码对话框重新出现；输入正确的实例密码后，独立 SFTP 确认原路径消失。脚本断言浏览器永久删除确认总数恰为两次，未绕过确认或直接调用删除 API。客户端正常退出，机器记录 cleanExit=true、进程退出 0。
