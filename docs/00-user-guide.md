# TandemSSH 中文操作手册

适用版本：v0.2.0 正式版。本文按当前中文界面和代码入口编写；早期研发记录中的“尚未实现”只代表当时状态。

## 1. 第一次使用：先连上服务器

1. 安装 Windows EXE，或完整解压 ZIP 后启动 TandemSSH.exe。
2. 桌面版会自动进入本机工作区，不需要注册、登录或记住应用账号密码。首次启动时等待本机数据初始化完成即可。
3. 在主机管理中添加服务器：填写名称、IP/域名、SSH 端口（通常是 22）、服务器用户名，以及密码或私钥认证信息。
4. 保存主机，打开它的 SSH 终端。首次连接按提示核对服务器指纹；需要验证码或二次认证时，按弹窗填写。
5. 在终端输入 pwd 并回车。能看到远端目录，就说明已经连通。

单纯使用 SSH、文件管理和监控不需要模型 API Key。AI 需要另外配置模型接口；模型服务商可能按用量收费，软件本身不要求会员解锁。

| 设置模型地址、Key、模型 ID | “AI 对话” → “模型设置”                               |
| 临时顺序执行几条命令       | “AI 协作” → “命令流程”                               |

| 配置允许、确认、拒绝规则   | AI 协作面板底部“工具与设置” → “命令黑白名单”         |
| 收回自动执行的控制权       | AI 协作面板“立即接管”，或直接在终端输入              |

要让 AI 操作当前 SSH 会话，请打开终端里的“AI 协作 → AI 对话”。主聊天区只显示你的消息、AI 的必要追问和最终答复；计划、完整命令及终端输出收在“执行详情”中。

## 3. 第一次让 AI 执行

1. 先连接 SSH，并让终端停在命令提示符。
2. 打开终端右侧的“AI 协作”。面板默认就是“AI 对话”，不用再选择任务类型。
3. 第一次使用时点“模型设置”，添加并启用自己的接口地址、API Key 和模型名称。模型名称必须是服务实际支持的 ID；执行命令还需要模型支持工具调用。
4. 在聊天框直接输入想做的事，例如：

> 帮我查一下 Docker 都跑了什么服务，只做查询，不修改容器。

5. 直接按 Enter 或点发送按钮。Shift+Enter 用来换行。默认使用人机协作；模式、模型、服务和调用次数都收在“高级设置”里，平时不用展开。
6. 发送消息就代表允许当前任务执行安全只读检查。授权只作用于当前连接和当前任务，默认最多 10 次操作、15 分钟。
7. AI 会直接执行 `docker ps`，读取真实结果并继续完成必要检查；主聊天区最终列出容器、镜像、状态和端口，不再逐步询问“下一步”。
8. 只有 Docker 删除、执行容器内命令、重启服务、覆盖文件等可能改变服务器的操作，才会在对话下方显示具体命令或文件改动供你确认。
9. 用户配置的拒绝规则始终优先；命中黑名单的命令不会因为只读授权而执行。
10. 上传、下载、目录传输和本机文件授权统一收在“执行详情”里，需要时再展开。
11. 一轮完成后，直接在对话底部继续输入，例如“再查一下这些容器的端口和最近日志”。上一轮结论会自动带入，新一轮仍有独立的命令记录。
12. 左侧终端显示服务器原始输出；右侧对话显示问题、必要追问和中文结论。想自己处理时随时点“立即接管”，或直接在终端输入。

普通只读查询通常不会出现“等待本次授权”。终端状态无法确认或任务需要更大范围时，才会显示一次授权；“等待命令确认”只用于需要核对的完整命令；AI 需要信息时可直接在同一个聊天框回复。

## 4. 人机协作、自动执行和接管

| 方式     | 使用方法                                                                           |
| -------- | ---------------------------------------------------------------------------------- |
| 人工操作 | 直接在终端输入命令，无需创建 AI 任务                                               |
| 人机协作 | 安全只读查询直接执行；可能改变服务器的操作逐条确认                                 |
| 自动执行 | 先授权本次任务，在允许范围和预算内连续执行；遇到额外确认、拒绝或不明确结果仍会停下 |

想自己处理时，点“立即接管”，或直接在终端输入。人工操作完毕，核对服务器状态、目录和剩余计划，再重新授权交还控制权。

接管会停止后续自动派发，但已发送到服务器的命令可能仍在运行。需要停止当前前台程序时，再使用面板的中断操作或终端 Ctrl+C；中断不撤销已经发生的文件修改。

## 5. 自定义“先 A 后 B”的命令

### 临时执行一次

打开“AI 协作 → 命令流程”，填写任务名称，选择模式，在“命令顺序”每行写一条，例如：

    pwd
    df -h
    free -h

这是 Linux 巡检示例；其他系统可能没有相同命令。点击“检查计划与授权”，审阅并授权后按顺序执行。仅使用命令流程不需要模型 Key。

### 保存为以后重复使用的流程

1. 打开协作面板底部的“流程库”，新建流程。
2. 填写名称、说明、可用主机及顺序步骤。
3. 每个命令步骤填写程序、参数和执行目录；需要变化的值定义成参数，每次运行再填写。
4. 按需加入上传、下载或目录传输步骤。模板保存用途名称，运行时再选择本机来源或目标。
5. 保存后，选择当前主机与参数，先预览，再创建任务并授权执行。

部署流程可以编排为“上传制品 → 备份现有文件 → 更新文件 → 重启指定服务 → 查询状态”。具体目录、服务名和覆盖范围需要按你的服务器填写。

简单命令列表不是完整 Shell 脚本编辑器。管道、重定向、多行脚本等使用显式脚本步骤，仍受解释器规则和人工审阅约束。流程的 secret-ref 秘密参数执行通道尚未开放，不能当成已支持功能使用。

## 6. 黑白名单怎么配

1. 打开“命令黑白名单”，新增作用范围：全局、分组、主机或任务。
2. 添加规则，选择“允许 · 白名单”“需要确认”或“拒绝 · 黑名单”。
3. 选择按程序名匹配，或按“程序名 + 完整参数”匹配；填写原因便于以后理解。
4. 使用界面的规则试算检查示例命令，再保存规则。试算不执行命令。

示例：允许 pwd；允许 df 且完整参数为 -h；把服务重启配置为需要确认。按“程序名（任意参数）”放行会允许该程序的其他参数，不适合只想放行某一种操作的情况。

拒绝规则优先于允许和本次授权。严格白名单只放行明确允许的操作，同时拒绝无法可靠判定行为的 Shell、解释器等入口。修改规则后，旧任务需要重新核对授权。

规则限制 AI、MCP、命令流程和受控入口。按你已确认的设计，人工终端保留自由操作；这些规则也不是远端系统沙箱。

## 7. 上传、下载和在线编辑

1. 打开目标主机的文件管理，进入需要操作的远端目录。
2. 上传：选择本地文件或目录，查看目标与冲突预览，确认后开始；在传输队列查看进度和结果。
3. 下载：选择远端文件或目录，选择本机保存位置，确认覆盖策略后开始。
4. 编辑：选择支持编辑的远端文本文件，在内置编辑器中修改并保存。出现版本冲突时，先比较远端内容和自己的修改，再选择处理方式。
5. 文件属性中可查看或修改受支持的权限；远端账户仍必须有相应操作权限。

让 AI/MCP 上传或下载时，还要在该任务里选择本地来源/目标并授权文件范围。仅在聊天中输入一个电脑路径不会授予文件访问权限。

暂停或重启后，使用对应的恢复入口核对来源、目标和已有结果，再继续。出现“结果未知”时先核对，不要直接重复部署操作。

## 8. MCP：让外部 AI 使用同一会话（可选）

使用内置 AI 不需要配置 MCP。只有想让 Codex 等外部客户端操作同舟 SSH 时才需要：

1. 保持同舟 SSH 桌面运行，先保存主机。
2. 打开“用户资料 → MCP 接入”。
3. 输入客户端名称，选择允许访问的主机，点击“创建配对”。
4. 复制界面生成的配置，放入相应客户端的 MCP 配置。使用当前界面生成的程序路径和标识。
5. 外部客户端创建任务后，回到同舟 SSH 授权。命令仍在同一终端执行，仍可查看、接管，并受同一规则约束。

## 9. 记录、备份和更新

- 记录：查看任务操作及历史详情，区分来源、命令、目标、输出和退出码。可导出脱敏记录；默认按 7 天 / 100 MiB 留存。完整终端录制需另行开启，不等于默认操作日志。
- 备份：“用户资料 → 数据”，先预览再导出或导入。密码、私钥、模型 Key、MCP 配对和任务授权不随配置迁移；恢复后重新配置凭据和必要的绑定。
- 更新：安装版启动时检查，运行期间每 20 分钟检查一次，也可以点“检查更新 / 更新版本”。发现新版后由你点击下载和重启安装。免安装版可下载新版 ZIP 完整解压使用。

## 11. 常见卡点

| 现象                  | 处理方法                                                                  |
| --------------------- | ------------------------------------------------------------------------- |
| 找不到 AI 协作        | 先打开主机的 SSH 终端，在终端界面找“AI 协作”；文件管理或首页不是这个入口  |
| AI 只说明计划，没执行 | 确认 SSH 仍连接、模型支持工具调用；若对话显示“下一步”，按其中唯一操作继续 |
| 模型认证失败          | 核对模型接口地址、Key、模型 ID 及该 Key 的权限                            |
| AI 提示额度或限流     | 查看模型服务额度；与软件会员无关                                          |
| 任务不往下走          | 查看等待授权、等待本步确认、补充信息、预算或规则拒绝提示                  |
| 接管后 AI 不继续      | 人工核对结果和终端状态后重新授权                                          |
| 文件保存失败          | 核对远端权限、文件是否已被修改、空间是否充足及冲突提示                    |

建议首次直接测试：连接服务器 → 打开 AI 协作 → 输入“帮我查一下 Docker 都跑了什么服务” → 发送 → 在同一段对话查看 `docker ps` 的真实结果和中文说明。
