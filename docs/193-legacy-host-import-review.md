# 旧主机文件导入：增加显式预览确认

2026-09-12。核对旧入口后发现：桌面 runtimePolicy 已在 database.ts 的旧 /database/import、/database/export 路由前返回 CONFIGURATION_BACKUP_REQUIRED；但 HostsPanel 的 JSON 和 SSH 配置导入仍在选取文件后直接调用批量导入接口。

本轮修复后，选择文件仅进行本地读取、解析及原生确认预览。JSON 显示连接名称/地址/端口、覆盖模式、随文件导入凭据的数量，并提示高级配置仍会提交；SSH 配置显示 Host/HostName/Port/ProxyJump 声明和覆盖模式，最多 400 行，明确不是后台解析结果。预览不枚举密码或私钥字段。取消直接返回，不调用导入接口。覆盖选项在异步文件读取前快照，确认后提交相同选项。两类文件均限制为 8 MB。

## 文件责任与验证

HostsPanel 仍负责编排文件选择、预览确认、提交及刷新；后端导入和授权契约未改变，未新增共享模块或跨层依赖。新增文案均提供中文与英文。

ESLint、TypeScript、差异格式检查通过，中文缺失键 0。代码核对确认取消分支位于两种导入 API 之前；本轮尚未完成打包桌面取消/确认实际操作验证，不把静态检查当作 UI 实测。

## 剩余风险与下一步

A22 保持未完全验证。旧 bulk-import 仍保留多种高级字段，例如 terminalConfig、tunnelConnections、statsConfig；单凭字段持久化不能证明会自动执行，需分别检查消费者和桌面自动化禁用规则。当前预览是摘要确认，未逐项展示全部高级配置或覆盖差异，不能替代完整安全导入设计。现有后端路由也没有绑定预览令牌。本轮不宣称所有导入安全，也不将尚未发布的改动视为 alpha.9 已包含。
