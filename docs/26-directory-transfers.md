## 已实现的行为

来源扫描固定条目集合，包含空目录；重叠选择不会重复下载。同一预览绑定用户和原始主机身份，每个条目准备时复查路径与属性，再使用既有完整 SHA-256/分块摘要流程。链接和特殊文件明确列为排除项，不自动跟随。源名称包含当前传输接口不支持的控制字符时列出跳过原因，不能把它拼入命令。

目录预览不是服务器文件系统的原子快照，文件内容摘要在各文件准备时取得。预览后新增的文件不自动加入本次集合；属性变化或服务器身份变化使该项准备失败。不能将这个属性约束说成整批内容已经在最初扫描时固定，也不能声称抵御服务器外部进程的原子竞态。

原生目标必须由系统文件夹选择框提供。映射只含条目 ID、父 ID、名称、类型和大小；解析后不能逃出所选根目录。预览只读取属性和已有文件摘要，不创建目录、不覆盖文件。已有目录必须明确合并，已有文件必须明确覆盖；也可以改名或跳过，跳过父目录会跳过子树。确认绑定当前预览版本，不能复用旧版本决策。

Windows 名称检查采用保守的可移植规则，拒绝设备名、分隔符、控制字符、结尾空格/句点及大小写折叠后的同名映射；参考 [Microsoft 文件命名规则](https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file)。大小写敏感目录的特殊兼容没有在此声明。

目录按父子顺序创建，每项返回 created/merged/skipped/failed/unknown。创建成功而后续校验失败保持 unknown；不会自动重试或清除这类记录。目录/父目录被替换为链接时拒绝子文件绑定。文件仍经原有临时文件和摘要校验提交；完成后可回收分块能力，最终文件保留。取消和重置不递归删除用户目录。

来源每批最多 4096 项、深度 64、描述元数据 2 MiB；最多两个扫描并行、全局 16 份/每用户 4 份预览。来源预览当前在条目准备时延长 30 分钟有效期。原生目标每份同样限制 4096 项和 2 MiB，全局最多 8 份/每窗口 4 份；确认后的清单不可重新指向别处。批次长时间传输的保活和结束后的整体回收要在队列接入时一并补齐。

## 已验证

真实本机 SSH/SFTP 检查递归集合、中文/空格/百分号名称、空目录、实际目录链接、属性与主机变化、取消、深度和数量限制；HTTP 检查 API Key 拒绝、跨用户隔离、禁止替换条目原始路径。夹具现在返回实际 realpath 和链接属性；Windows 上的 POSIX 所有者语义仍是模型，不能替代 Linux/OpenSSH 验收。

本地文件测试检查预览无写入、明确覆盖/合并、完成后文件字节保留、父目录链接替换、未知创建结果、并发绑定与能力容量预约。IPC 检查非主框架拒绝与账号重置后的目录能力失效。

文件联合回归 13 个文件/98 项通过；加入 HTTP 和未知创建结果后，最终专项 4 个文件/25 项通过（.cache/download-tree-core-final-tests.log）。发现并修复共享类型缺少 ESM 扩展名，以及创建结果标志与文件属性变量重名造成的目录状态回归。验证结果不包含尚未接入的整批 UI。

## 中文整批界面与共享队列已接入

DownloadTreeDialog 负责来源/目标预览、逐项改名、冲突决策和确认后的批次交接；download-batches.ts 负责目录结果、成员关系、保活、累计结果和整体释放；download-bindings.ts 定义受控的来源准备、目标绑定与完成回收适配。DownloadQueue 继续拥有唯一的分块传输、并发、暂停恢复和未知结果状态机，未复制第二套文件读写流程。目录和文件结果统一进入队列，并提供分页和整批提示。

FileManager 的目录与多选下载不再过滤掉目录；右键菜单也补齐了目录/所选项入口。已有目录合并和已有文件覆盖均需明确选择；改名后必须重新检查目标，旧冲突决策清空。确认后关闭文件标签不会放弃已交给全局队列的批次；确认前关闭弹窗释放两端预览。已完成文件不会被重试再次覆盖。

打开客户端时为活跃/暂停文件与批次做定时保活，避免长文件或暂停导致后续条目过期。完成文件的来源和原生块清单及时回收，最终文件与显示结果保留；清除最后一项时释放批次预览。重置改为先撤权、等待在途操作收敛，再逐项关闭/清理，避免超过内部并发上限时漏掉暂停文件。整批统计保留已清除项的累计结果，不因清除已完成行而倒退。
