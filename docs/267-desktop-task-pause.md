## 实际用户路径

三步流程：printf 首步标记、sleep 10、pwd。在第二步运行中点击独立“暂停任务”，等待 paused-human，保留未知记录；脚本不发送 Ctrl+C，等待远端自行结束并通过实际终端输出核对。随后重新授权，分别执行跳过、重试；自动与协作共四个组合。

全部验证：同一 workflowRunId、首步只执行一次、旧未知操作保留、暂停期间没有新增模型请求；协作恢复继续逐条批准。跳过为完成但有异常，重试成功为完成。客户端正常退出，后台端口释放。

## 实际 HTTP 检查

在客户端同一实例请求生产路由：

- 已登录但 body 带 interrupt:true：400 INVALID_REQUEST，任务未暂停。
- 非 UUID 任务 ID：400 INVALID_REQUEST。
- 不带登录凭据的请求：401 或 403，任务未改变。
- 独立按钮正常请求暂停后，再以空 body 暂停同一任务：200，状态不变且控制 epoch 不增加。
- 已完成任务再次暂停：400 TASK_STATE_INVALID，不复活任务。
