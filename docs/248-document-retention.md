# 文件编辑连接持有与关闭边界

2026-09-13。

本轮核对 A33（关闭终端仍有编辑/传输，不提前释放连接、不丢未保存草稿）的实现边界。

## 当前实现

文件浏览通过独立的 file-manager SSHSession，文档 production target.retain 增加 activeOperations；文件会话 cleanupSession 在计数大于零时推迟清理。DocumentService 管理每个打开文档的持有者，在文档关闭、过期或服务销毁时释放。此描述不能代替真实终端标签关闭的组合验收。

FileWindow 的保存草稿并关闭已检查保存成功且当前草稿仍与发起保存时一致；保存期间出现新编辑不会按旧保存结果关闭。本轮保留该既有保护，没有重复改造。

## 新增验证

document-service.test.ts 使用实际 DocumentService 和受控 RemoteFileIO/连接持有计数，新增：

- 两个文档分别持有连接；关闭第一份两次后，只释放一份，第二份仍能实际保存中文内容，最后关闭才归零。
- 其他用户尝试关闭文档，不释放其持有、不使原版本失效；原用户仍可保存。
- 服务销毁释放全部剩余持有；重复销毁不重复释放。

运行文档服务、草稿 Hook 与文档 Hook 三个测试文件：36 项通过。一次新增测试错误地假定保存响应包含 content 字段，实际契约只返回保存元数据；改为核对受控文件存储字节后通过，非生产缺陷。

TypeScript 与该文件 ESLint 通过。生产文件无修改；新增验证仍在现有文件职责内，没有共享模块或依赖变化。

## 尚未闭环

上述证据覆盖文档持有与草稿异步边界，不证明正在上传/下载时关闭真实终端标签的整个行为；仍需桌面组合验收，A33 保持 not-fully-verified。未提交、推送或发布。
