# 权限确认操作固定原连接

2026-09-12。PendingSudoOperation 原先只保存路径/文件，未保存触发权限确认的会话；提交回调使用当前 sshSessionId，连接重建后存在把旧权限操作应用到新会话的风险。

待确认导航/删除现在携带原 sessionId。提交密码前、密码保存成功后、每次删除前以及导航结果更新前检查当前会话仍相同；密码和删除始终发送到原 ID。旧请求失败且连接已变化时也不会重开旧密码窗口，而是清除待操作并提示“连接已变化……刷新后重新发起”。普通人工权限确认流程保留，不自动提权或自动重新授权。

文件操作领域 assertFileSession 与 runFileBatch 的组合测试：首项后切换连接，后续项被拒绝且确认计数保留。现 3 项通过，翻译缺失键 0，tsc -b 通过。FileManager 仍有原有一条 windowId 未使用 lint 警告，新模块/测试无错误。

本轮未向服务器提交 sudo 密码或执行删除；类型与控制检查证明代码接线，完整权限对话框的断线重连实机验收仍需完成。此修复不声称覆盖用户取消对话框的全部异步情况。
