# 在线编辑器搜索替换汉化

2026-09-12，B08 基础在线编辑验收发现 CodeMirror 搜索面板未配置语言短语，中文应用内仍显示 Find / Replace 等英文。

CodeEditor 通过现有 i18n 与 EditorState.phrases 提供查找、替换、上/下一个、选择全部匹配、大小写、正则、全词、关闭、跳转行以及读屏结果提示。中英文分别维护，保留 CodeMirror 的 $ 占位语义；编辑器配置随翻译函数变化更新。业务编辑组件负责适配第三方编辑器，没有新增共享抽象或跨层依赖。

实际组件测试打开搜索面板并核对中文可访问名称；查找 hello、全部替换为同舟，随后 Ctrl+Z / Ctrl+Y 验证撤销和重做。没有模拟 CodeMirror 本身。jsdom 缺少 Range.getClientRects，首次出现未处理测量异常；测试中局部补齐两项 Range 几何接口并最终恢复，不声称测量或桌面几何已验证。

编辑器与 use-file-document 两文件共 10 项通过，覆盖本次文字操作及已有空文本保存、保存中继续编辑、冲突草稿、未知保存结果、另存目标刷新。翻译缺失键 0、ESLint 通过。B08 的完整多文件标签与桌面操作链仍待归并验收，本次不标记整体完成。公开 alpha.5 未含此汉化。
