# 权限接口拒绝最终链接路径并核对退出结果

2026-09-13，A34 后端修复，接续 262。

## 修改

changePermissions 路由验证 path 为非空字符串、最多 4096 字符且无 NUL。构造 chmod 前去除尾部斜杠（根目录保持 /），在同一 exec 命令内先判断最终路径是否为符号链接；命中时退出 65，并由路由返回 409 / FILE_SYMLINK_TARGET_REQUIRED。调用者应选择目标文件本身，不能依靠传入链接隐式修改目标。

成功必须同时满足退出码 0 与完整 SUCCESS 标记。原先包含 SUCCESS 即成功、或退出 0 且无标记仍成功的分支已移除；不能核实的结果返回失败说明。

文件职责仍在既有权限接口内，没有新共享模块或依赖变化。普通文件和目录命令继续使用现有 execChannel，特殊权限位及字面路径引用保持。

## 实际验证

修复前三项结果分类测试失败；修复后权限路由 20 项通过，包含所有权、完整八进制、非法路径、链接拒绝、非零退出与缺失标记。

隔离 Alpine OpenSSH 实例 64cce878-17ab-4580-a968-c5587f26de72：permissions-acceptance.test.ts 一个实际集成场景通过，内部回归目录 1777/2755/0755/0700、文件 4755/2750/0644 七次模式并逐次 SFTP 读回。

新增文件链接、目录链接和目录链接末尾斜杠三次请求，均返回 409 且各自目标 mode 不变。字面特殊字符路径无注入标记，非法 888 保持拒绝。报告 .cache/permission-target-linux-results.json，日志 .cache/permission-target-linux-tests.log。

实现过程中自动编辑曾留下重复代码块导致语法错误，修复后才运行通过，不把该脚本编辑错误列为产品运行失败。

## 限制

检查最终链接与 chmod 之间仍可能被外部进程替换，不声称提供跨进程原子 no-follow 保证；中间路径组件的链接不是本轮禁止范围。既有超时和通道生命周期没有在本轮重构，A34 仍需整体审阅及最新桌面组合验证。
