# 独立桌面 C2S

状态：实施中。

现状核实：主界面使用本机主机列表，但 Electron C2S 中继地址和 JWT 固定取 Remote Sync，独立桌面无法使用且可能误用两个数据库的数字 ID。本轮改为明确的本机 C2S：固定回环中继地址，不回退远程同步。旧配置需重新选择主机，不自动切换来源。

c2s-session.cjs 拥有可信主窗口校验、本机 JWT 的内存生命周期、登录代次和固定中继地址。登录变更、注销和窗口销毁撤销现有隧道；不把 JWT 写入隧道配置。IPC start/test 绑定当前代次，后续建立中继前重新检查，阻止迟到的旧请求。UI 手工选择主机时保存 IP/端口/用户名快照；后端在发起 SSH 认证前核对当前主机身份，变化则拒绝并提示重新选择。已有后端旧协议兼容不变，新桌面强制声明本机来源及快照。

主进程只负责本机监听与中继；后端沿用主机权限和信任机制。界面显示本机中继、旧配置复核与身份变化的中文错误。验证真实 IPC/local/remote/dynamic、身份变化、旧配置、登录撤销、停止与端口冲突，不以单独后端中继测试替代桌面入口。
