# 普通删除的有界等待与迟到结果

2026-09-12。补齐 172 中普通永久删除在通道排队、协商或远端执行无响应时的等待上限。修改限于 operation-routes.ts 的普通删除分支，sudo 分支继续使用 173 的独立有界执行。

每次普通删除尝试最多等待 60 秒。尚未派发时到期返回 DELETE_NOT_DISPATCHED；已派发后到期返回 DELETE_RESULT_UNKNOWN。已有中文错误适配沿用。到期结算后关闭本次通道；迟到的通道回调只关闭通道，迟到成功、权限失败、额外输出均不会改写结果或转入 sudo。明确结果和打开错误都会清理定时器，正常权限拒绝转入 sudo 前也结束原普通尝试的计时。

超时不能证明远端已回滚或没有发生变化；批次按既定规则停止并要求核对，未新增自动重试。普通尝试和随后经既定流程授权的 sudo 尝试分别具有各自的上限，不宣称整个两阶段请求只需 60 秒。
