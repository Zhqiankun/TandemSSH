## 速度与剩余时间显示

后续核对发现上传和下载的估算逻辑不一致：下载缺失 size 按 0 计算，可显示负数 ETA；两侧速度均整除取整，低速会显示 0 KiB/s。新增文件传输领域 transfer-estimate.ts，只有完整有限且一致的总量/完成量和正速度才产生估算，溢出不显示；速度保留三位有效数字。UploadQueuePanel / DownloadQueuePanel 只在实际传输状态调用，暂停等状态不显示旧估算。

这是两个相同字节进度语义调用方共用的纯显示函数，所有者为文件传输模块，单向供两侧面板使用，不访问 API、不更改队列状态/计数。正常、零字节完成、低速、未知总量、负值、NaN/Infinity、越界进度及数值溢出的两项数据测试通过。仍不将单纯估算等同于真实网络速度保证。
估算变更的 ESLint 通过；修正测试联合元组展开后 tsc -b 和两项估算测试复测通过。
