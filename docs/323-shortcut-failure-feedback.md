# 快捷键异步失败反馈与复制选择保留

2026-09-13，继续 F03/B03。

keybinding-dispatch 新增可选 onFailure 回调，片段读取和通用粘贴 Promise 的失败被捕获，连接已变化的迟到失败不再提示旧操作。Terminal 提供统一中文错误提示，不传递底层异常消息，避免错误中含主机或凭据细节。终端片段读取适配器不再把读取失败吞成 undefined，而抛出固定 SNIPPET_READ_FAILED，由派发层处理；实际不存在的片段仍保持既有无发送行为。

复制操作等待 writeTextToClipboard 成功返回 true，且当前选择仍等于本次复制的文本时，才清除选择。返回 false 或拒绝时保留选择并提示；等待期间用户改选的文字不会被迟到成功清除。

边界仍为 Terminal 编排→keybinding-dispatch 异步派发→既有剪贴板/读取适配器，没有新连接、重试或后端协议。提示只说明操作失败，不把任何传输异常擅自判为零字节写入。
