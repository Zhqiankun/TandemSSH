# sudo 删除失败后清除旧密码并允许重新操作

2026-09-12。后端永久删除在 sudo 返回失败或 Promise 拒绝后仍保留 session.sudoPassword，错误密码会被后续操作重复使用，无法回到输入密码流程。

operation-routes.ts 捕获本次使用的密码，失败时仅当缓存仍为该值才清除；并发设置的新密码保留。成功时继续保留现有缓存。失败统一返回 SUDO_DELETE_FAILED，不将未经确认的结果分类为认证失败，也不自动重试或继续删除。

现有文件错误适配器允许该错误码通过，仍只保留错误码和状态，不复制请求凭据。普通删除和 sudo 提交的失败提示新增中英文说明：先核对文件状态，再重新发起操作并输入密码。部分批次继续使用已有已确认/未确认计数。

文件责任和依赖方向不变：文件管理路由管理本次执行及会话凭据，文件 API 保留受限错误信息，页面编排用户反馈。没有新增模块或共享抽象。
