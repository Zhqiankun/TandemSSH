## 实现

新增 electron/c2s-config-store.cjs，唯一负责 c2s-tunnels.json 的读取、原子替换、快照摘要及持久化导入收据。既有普通保存和启动读取均改走该入口。新 snapshot/import IPC 只允许 C2sSession.trusted 校验的主窗口调用，调用方不能指定文件路径。preload 和 Electron TypeScript 契约同步。

普通保存捕获校验前的文件摘要，异步端口检查返回后再次核对，避免覆盖期间发生的新写入。导入也要求预览时摘要一致；使用同目录独占临时文件、fsync、关闭后rename替换。替换失败保留原文件并清理本次临时文件。文件过大、损坏或空文件均拒绝覆盖。

首次导入将旧数组升级为 {version:1,config,receipts} 文件。配置与收据一次原子替换，不使用可能与配置提交脱节的旁路收据。旧数组仍能读取，尚无收据的普通保存继续保留数组格式。有收据的普通保存保留收据。

相同导入ID及相同有效内容返回持久化结果，不再次追加；ID相同但内容变化拒绝。即使用户后来手工删除导入项，重试也不复活已删除条目。收据不自动淘汰，达到1024收据/2048配置上限时明确拒绝新导入。8MiB文件限制。

导入字段严格投影，autoStart恒false，清除 relayOrigin/sourceIdentity/会话epoch/诊断/秘密字段；不能通过写入导入文件获得本机审阅状态。后续界面需明确让用户重新选择并审阅目标主机。没有触发启动、监听或网络探测的调用。

中英文新增冲突、格式、大小、写入、确认及容量错误；普通保存错误也通过现有C2S错误映射展示。
