# 运行时间与系统信息的局部失败处理

2026-09-13，F13/B12。

原 uptime 采集将空文本转换为 0，允许负数、指数格式和不安全数字，非法值还可能保留 NaN/Infinity。系统信息三个串行命令任意一个抛错，最终会丢弃全部字段。

修复：

- uptime 要求成功退出及两项非负十进制 /proc/uptime 字段，拒绝缺项、额外字段、非数字和不安全数值；无效结果统一 seconds/formatted=null。合法 0 与小数保留。返回字段及 d/h/m 文本格式保持兼容。
- 主机名、内核、OS 独立读取并各自处理失败，只保留成功命令的非空输出。仍通过既有固定只读监控执行层及其并发限制，不进入交互终端。
