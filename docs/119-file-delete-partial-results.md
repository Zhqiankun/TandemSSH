# 批量删除部分结果提示

2026-09-12，B09 核对发现批量删除中途失败时只提示通用失败；回收站不可用后经用户确认的永久删除分支缺少内部错误处理，可能抛出未捕获拒绝。

新增文件操作领域 runFileBatch：顺序执行，首个拒绝即停止，仅统计已确认成功数，返回错误供 UI 分类。两个删除分支共用这一语义，不自动重试、不把失败响应称为未执行或已回滚。原确认和永久删除确认步骤保留。

普通部分失败显示中英文完成数与“结果未确认或尚未执行”数量，提示刷新核对；永久删除后备分支捕获中途失败、保留确认数，并仅刷新原目录或使原目录缓存失效，避免刷新用户已切换的新目录。后台删除/回收站及权限边界未改变。
