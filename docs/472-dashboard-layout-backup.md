# 仪表盘自定义布局备份

2026-09-14。统一审计F14/B15时确认：UiPreferences预设不等于用户自定义布局；dashboardTab.slots、dashboardTab.mainWidthPct和dashboardView原先不进入备份。本轮补齐实际本地字段。

## 契约

新增types/desktop-layout.ts，限定卡片ID、main/side面板、唯一slot key、顺序、尺寸及宽度范围；只承载无执行行为的布局。前后端共享该契约，不依赖DashboardTab页面内部类型。

备份格式3新增可选desktopLayout。桌面捕获当前卡片排列、左右宽度和默认页；导出预览保存实际布局。导入仅在勾选界面偏好恢复后返回布局，持久化到现有导入收据，再由桌面localStorage适配器应用。布局没有对应数据库列，不将本地布局伪写入用户数据库字段。

字段缺省代表旧备份不覆盖；null明确代表恢复默认（删除该localStorage键），避免把目标旧布局当成源默认值保留。新增字段参与现有本地预览变化检查。本地恢复先验证全部输入，修改失败时连同已删除的布局键一起回滚。沿用手动重新加载，不擅自关闭活动会话。

## 责任

desktop-layout拥有备份显示契约；desktop-configuration适配本地键；schema/http/service负责校验和预览；Repository负责独立恢复选择及收据。没有新增通用utils，没有后端依赖页面或自动执行行为。中英文选项说明增加“仪表盘布局”。
