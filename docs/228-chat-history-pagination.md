# 普通聊天历史游标分页

## 实现与契约

历史列表不再只有无法继续的最近 50 条。AiRepository.listConversationPage 按 updatedAt DESC、id DESC 排序，查询 51 条，返回最多 50 条与 nextCursor。后续页选择时间更早或同时间 ID 更小的记录，始终限定当前用户。

GET /ai/conversations 保留 conversations 数组，新增 nextCursor（无下一页为 null）；可选 cursor 是更新时间/ID 的 JSON 字符串，由 query 参数传输。conversation-cursor.ts 只属于聊天协议，严格验证字段、日期字符串形态、正安全整数与 256 字符上限；非法值返回 400 INVALID_CONVERSATION_CURSOR。游标不授予权限、不接受用户身份。

前端新 getAiConversationPage 返回页对象，原 getAiConversations 继续兼容。AiConversationPicker 增加中文“加载更早会话”，追加时按 ID 去重，失败保留已有行与原游标。刷新成功替换为最新页。仅切换所选会话不会清空已加载旧页；聊天流状态变化仍刷新近期列表。

依赖方向：界面目录组件 → 公共 API → HTTP 游标解析 → 仓储查询。无数据库迁移、共享工具库或写权限变化。

## 验证

- 真实磁盘 SQLite 写入 103 个同时间戳会话，按 50/50/3 读取；首次读取后插入更近期记录、删除已读记录，后续页仍精确覆盖原 103 个 ID，无重复。刷新首屏显示新记录，其他用户数据不混入。
- 游标解析覆盖空值、非法形态、额外 userId、超长和非法 ID。
- UI 验证加载更早、重复 ID 去重、旧会话选择、刷新清页，以及下一页失败后原游标重试。
- 真实 HTTP 验证编码后的游标传入仓储时身份固定为 owner，夹带 userId 的游标返回 400 且不查询仓储。

数据库、游标和 AI 界面 **9 文件、47 项通过**；追加 HTTP 文件 **5 项通过**。TypeScript、修改文件 ESLint、翻译检查通过，字面缺键为 0。

首轮一个旧面板测试在目录选项尚未加载时触发选择而失败；增加等待实际选项后复测通过，没有改掉产品失败提示断言。

## 限制

这是实时分页，不是不可变历史快照。分页过程中被重新聊天更新到首屏的会话需要刷新查看；不宣称任意并发修改下旧页完全静态。新按钮尚未做打包桌面点击，既有历史入口真实桌面证据见 227。并发聊天和全局资源上限仍需完成；未发布新安装包。
