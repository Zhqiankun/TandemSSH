# 内存零值与异常字段修复

2026-09-13，F13/B12 监控边界。

原采集器用真假值判断 MemAvailable，导致 0 kB（可用内存耗尽）整个指标为未知；usedGiB=0 也被变成 null。字段解析只取第一个数字，负数、小数或错误单位可被误解释，超出总量时又被夹成正常百分比。

现在 memory-collector.ts 严格识别唯一的非负十进制 kB 字段，并要求安全整数。有效总量独立保留；缺失、重复或无效可用量以及可用量大于总量时，使用率与使用量保持未知，不伪造 0/100。零可用量与零使用量按有效值处理。

返回字段仍为 percent/usedGiB/totalGiB，已有数值精度不变；不增加 API、共享模块或依赖方向。修改限于内存采样模块及测试。
