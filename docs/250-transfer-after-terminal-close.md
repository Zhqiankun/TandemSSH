# A33：传输进行中关闭终端的桌面闭环

2026-09-13。

## 标准与环境

A33 原始标准：关闭终端仍有编辑/传输，不提前释放连接、不丢未保存草稿。本轮补充其上传、下载两个方向，与第 248、249 号记录组合完成此项，不扩展为所有传输或断线恢复功能均已验收。

使用当前本地 Windows win-unpacked 包、真实 loopback SSH/SFTP 协议和 Windows ConPTY + Git Bash 终端。SFTP 文件位于工作区受限测试目录，权限是夹具模型，不能称为 Linux 权限测试。编辑侧的真实 Linux 证据在第 249 号记录。

两个客户端均为独立测试 profile；不使用业务服务器、收费模型或用户日常配置。

## 防止时序误判

下载在 beforeRead 挂起一次真实 SFTP 读取；上传在 beforeWrite 挂起一次真实 SFTP 写入。两者均先确认 ConPTY Shell 提示符出现，再开始传输。

在服务端挂起尚未释放、最终文件仍未提交时，切换到真实终端标签并点击关闭，等待终端标签消失。返回唯一的原文件管理标签，再次核对传输仍挂起，然后释放服务端读/写。

因此关闭发生在传输过程中，不是传输已经结束后才关终端。
