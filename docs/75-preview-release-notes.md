# TandemSSH v0.1.2 正式版

同舟 SSH 是 Windows 优先的人机协作 SSH 工作台，基于 Termix 改造。使用自己的模型 API 地址、Key 和模型名称，核心 SSH、协作和 MCP 功能不要求软件会员。

## 本次交付

- SSH 多标签、分屏、搜索、复制粘贴、命令历史和多种终端编码；支持 Windows 本机终端。
- SFTP 上传下载、目录传输、冲突预览、队列、暂停恢复、远程在线编辑及文件权限操作。
- AI 自动执行、人机协作、人工接管与执行时间线；Codex 等客户端通过本机 MCP 共用会话和规则。
- 自定义顺序流程与普通参数，上传/命令/下载组合及任务恢复。
- 主机、网络、终端主题、快捷键、界面和仪表盘布局备份；本地 C2S 配置导入和跨重启接续。
- 本地操作日志位置、脱敏导出、7天/100MiB留存及显式清理。
- Windows 安装版内置版本检测与更新，运行期间每20分钟自动检查。

## 已知限制

- 流程的 secret-ref 秘密参数执行通道尚未开放；普通参数流程可使用。
- 严格规则会拒绝已识别的 Shell/解释器与不透明入口，但不是远端操作系统沙箱，不能保证识别任意重命名二进制的行为。
- 配置备份不迁移密码、私钥、API Key、MCP配对和任务授权。恢复后需重新配置凭据；导入的隧道和快捷键保持禁用、需审阅。
- 新的本地 C2S 导入收据格式不保证旧版可读；降级前请保留数据备份。
- 第三方发行声明仍在持续核对，已知来源提示及完整功能验收状态保留在仓库文档中。
