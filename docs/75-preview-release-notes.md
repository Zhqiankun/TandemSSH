# TandemSSH v0.2.0 正式版

同舟 SSH 是 Windows 优先的人机协作 SSH 工作台，基于 Termix 改造。使用自己的模型 API 地址、Key 和模型名称，核心 SSH、协作和 MCP 功能不要求软件会员。

## 本次更新

- AI 协作改为连续对话：后续消息会继承同一会话上下文，可围绕部署、排障和巡检持续执行。
- AI 能按任务目标连续运行多条 SSH 命令，并根据上一条结果决定下一步；仅在缺少必要信息或命中授权规则时等待处理。
- 精简 AI 对话界面，把授权、策略和高级设置集中到“工具与设置”；主对话保留用户消息、执行结果和必要提示。
- 桌面版默认进入本机工作区，不再要求注册或登录应用账号。
- 自动命令在终端中只展示可读的实际命令和输出，隐藏用于状态追踪的内部 PTY 包装脚本。
- 修复模型配置保存、请求失败提示、启动初始化和连接恢复反复提示等问题。
- 保留 SSH 多标签、SFTP 上传下载、远程文件在线编辑、自定义顺序流程、人工接管、命令黑白名单、脱敏记录和 Codex MCP 接入。

## 下载

- `TandemSSH-0.2.0-x64.exe`：Windows x64 安装版。
- `TandemSSH-0.2.0-x64.zip`：免安装版，完整解压后运行 `TandemSSH.exe`。
- `SHA256SUMS.txt`：下载文件校验值。
- `latest.yml` 与 `.blockmap`：应用内更新使用的元数据。

全部发行文件由 GitHub Actions 从 `v0.2.0` 标签源码构建、验证并发布，不使用本机手工上传的安装包。安装版会在启动时检查更新，并在运行期间每 20 分钟检查一次；下载和重启安装由用户点击。

## 安全与控制范围

- 命令允许、确认和拒绝规则约束 AI、MCP、流程及其他受控入口；人工终端保留自由接管。
- 自动模式支持在单次任务范围内预先授权；明确拒绝的规则仍然优先。
- 操作记录默认保存在本机并脱敏，按 7 天或 100 MiB 上限清理；完整终端录制需要手动开启。
- 模型凭据保存在本机配置中，软件不代售模型会员；模型服务商可能按实际用量收费。

## 已知限制

- 流程的 `secret-ref` 秘密参数执行通道尚未开放；普通参数流程可使用。
- 严格规则会拒绝已识别的 Shell、解释器与不透明入口，但它不是远端操作系统沙箱，无法识别任意重命名二进制的实际行为。
- 配置备份不迁移密码、私钥、API Key、MCP 配对和任务授权。恢复后需重新配置凭据；导入的隧道和快捷键保持禁用、需审阅。
- 免安装 ZIP 不使用应用内自动更新，需要下载新版本后手动替换。

正式下载文件只会在 GitHub Actions 的类型检查、代码规范、测试、安装、升级及卸载门禁全部通过后发布。
