| 位置 | 责任 | 依赖边界 |

## 2026-09-07 MCP 桌面桥接、Codex 发现与真实 SSH 验证

本轮是实质进展。此前只有 MCP 工具工厂；现在已加入共享 schema、本机签名管道、OS 凭据配对、可运行 stdio、生产核心适配、桌面连接请求与中文设置。使用方式与限制见[第 13 份文档](13-mcp.md)。

新增责任边界：mcp/contracts.ts 管输入契约；bridge/client、server、protocol 管认证与消息顺序；pairing-registry 管范围与撤销；core 管到 TaskRuntime 的映射和输出投影；production 管仓库/会话适配；http-routes 管可信桌面接口；stdio 是独立协议入口。前端 mcp-api、McpSettings、use-mcp-session-requests 分别负责 API、配对界面和调用 AppShell 既有开终端函数。
