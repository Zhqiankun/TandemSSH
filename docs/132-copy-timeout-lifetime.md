# 复制超时后的通道生命周期

2026-09-12，alpha.6 标签之后的修复。

原复制路由的 60 秒超时仅回复 HTTP，排队的 SSH 通道仍可能稍后执行。现以 copyExpired 标记超时，在 execChannel 的 beforeOpen 检查时阻止过期/已断开会话派发；已取得通道时主动 destroy；迟到通道回调立即关闭，迟到成功事件不写入成功结果。超时响应为 COPY_RESULT_UNKNOWN，界面中文说明目标可能已有部分文件，刷新检查后再重试。关闭通道不等于回滚或保证已开始的远端进程停止。

17 项复制路由测试通过，新增排队超时和已打开通道超时两种生命周期场景；均验证超时后的 beforeOpen 拒绝、通道关闭、迟到成功不覆盖响应。后端 ESLint 无错误；UI 保留一条既有 windowId 警告；中文缺失键 0。此为通道夹具与虚拟时钟测试，非真实 60 秒远端网络中断验收。

文件责任仍为现有 action-routes 与 FileManager，未新增通用共享抽象。复制命名冲突与完整批量异常验收仍未解决，B07/B09 保持未完成。alpha.6 的已推送源码标签不变。
最终 tsc -b 类型检查通过。
