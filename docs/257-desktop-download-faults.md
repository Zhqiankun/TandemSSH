# 下载落盘故障的中文桌面反馈与恢复

2026-09-13，A32 桌面证据。

## 环境与注入边界

两次独立 Windows 客户端、各自 profile、真实 loopback SSH/SFTP。沿用现有本地目录包；下载落盘生产代码与当前源码一致，包未包含第 252 号无关 SFTP 分类修复，不称为全量最新发布包。

通过本次客户端主进程调试通道，只对报告目录内、名称为 .tandem-download-*.part 的文件句柄包装 write：前 65 次实际写入成功，第 66 次一次性返回 ENOSPC 或 EACCES。其他文件句柄不受影响。进程退出后包装自然销毁，没有修改磁盘权限、填满宿主磁盘或改写生产代码。

## 检查结果

真实远端文件大小 4,325,393 字节。每次失败后：

- 界面显示失败及对应中文说明：“本地磁盘空间不足，部分文件保留。”或“没有权限写入或替换本地目标。”
- 界面准确展示真实暂存路径，已校验进度为 4,194,304 字节。
- 实际暂存文件 4,259,840 字节，包含额外未验证尾部；最终目标尚不存在。
- 点击“核对后恢复”，恢复后完整文件大小和 SHA-256 与源数据相同，暂存路径消失。

两个客户端正常退出，后台端口释放，SSH/SFTP 夹具关闭。最初一次脚本因变量重名语法错误未启动客户端，修正并检查语法后再运行，不作产品失败证据。
