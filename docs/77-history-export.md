# 任务历史脱敏导出与撤销验收

状态：实施中，2026-09-11，基线 bdbbcc7。

原始 A25 要求 MCP 撤销后不接收新操作、导出不含已知秘密；F08 要求操作来源、状态、输出等执行记录可见。现有任务历史只有查询/详情，底座管理员审计导出不是同一份任务记录。本轮补当前任务或全部保留任务记录的中文导出入口，继续验证真实 MCP 配对撤销。

文件责任：AuditHistoryReader 拥有用户目录、分片校验、过滤、再次脱敏和逐条扫描；AuditJournal 等待既有写队列后提供导出入口；audit/history-export-http.ts 只处理 HTTP 流、背压、取消与错误。接口挂在既有可信用户路由下，只接受 taskId，不接受目录、文件名或其他用户身份。依赖从 HTTP 到审计服务和类型契约，审计层不依赖 AI、页面或其他模块的私有实现。

格式为 UTF-8 NDJSON：header、逐条 record、summary。开始时固定文件集合及时间上界；导出期间的新记录不保证包含。损坏/消失/过期记录按既有保留规则处理，损坏或消失计入 skipped。上限 256 MiB、单帧 4 MiB、100 万记录和 4096 分片；超限或中断不会形成成功下载。只允许单个导出扫描，保持最多一个分片和一个输出帧的服务端内存；HTTP 背压、请求关闭及总期限负责中止。

UI API 沿用 authApi 的 Axios Fetch 流适配器和鉴权拦截器。专属流读取器检查格式、计数、结束标记及容量；只有完整接收并验证 summary 后才生成 Blob 下载。组件负责中文范围/进度/取消/结果，切任务、账户或关闭窗口会取消未完成导出；不自动导出或上传第三方。资源受控，不复用普通聊天或管理员审计的私有代码。

验收：全部记录超出一页、任务过滤、用户隔离、秘密再次脱敏、损坏计数、取消和超限、半份结果禁止下载；真实 Windows UI 下载并读回 NDJSON；真实 MCP 撤销后拒绝新请求和重新配对前的连接；自动/协作基线不缩减。
