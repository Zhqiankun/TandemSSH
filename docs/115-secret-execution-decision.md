# 秘密步骤执行通道：待确认的行为边界

2026-09-12。现有 PtyCommandExecutor 明确使用共享 Shell，并依赖终端回显过滤普通命令；输入经终端行规程处理，不能直接将秘密写入当作普通参数。secret-ref 安全存储不等于安全传输。

待用户确认的选择：复用当前 SSH 连接的独立无 PTY 标准输入通道，或者必须继承共享 Shell 环境。前者避免终端输入回显，步骤必须显式目录，不能继承共享 Shell 临时 export；后者需增加终端模式握手、输入隔离与恢复机制，人工接管时还必须防止后续人工按键被秘密读取过程消费。两者均需用途授权、每次写入前控制权检查、有界输出和秘密脱敏，不能自动转换为 argv 或环境变量。

本次通过异步问题请求用户选择，因为这影响已约定的共享 Shell 行为；未在用户选择前修改生产执行通道或放开 SECRET_TRANSPORT_UNSUPPORTED。存储和用途边界可以独立继续，但不能声称整个秘密流程可用。
