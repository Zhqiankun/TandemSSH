# 修复非覆盖导入未跳过重复连接

2026-09-14。界面“导入(跳过已有)”与实现不一致：后端仅overwrite=true时读取已有主机，因此非覆盖导入总会新增，同一文件重复项也会新增多份。

host-bulk-routes.ts的JSON与SSH配置导入都先读取当前用户已有连接。非覆盖模式命中地址/端口/用户名时计入skipped并跳过后续主机处理；成功新增后把新ID加入本次索引，使同批后续重复项也能跳过。覆盖模式保持明确唯一目标更新及383的歧义拒绝；本次新建记录也进入索引。索引仍是请求内状态，无新共享模块或依赖变化。

已有主机读取失败时同样在开始导入前拒绝，不能在未知数据库状态下假装完成跳过。该改动不是跨请求事务或并发唯一约束，不声称两个同时导入请求不会竞争。

真实HTTP→仓储→SQLite新增四场景：两种格式分别在已有/无已有记录情况下导入两个重复项。修复前四项都重复新增；修复后已有时新增0/跳过2且完整原快照不变，无已有时新增1/跳过1且保留首项名称。
